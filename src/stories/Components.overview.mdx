# Components

aero-ds provides a comprehensive set of UI components for building Birdeye SaaS interfaces.
All components are built on Radix UI primitives, styled with Tailwind CSS, and use the aero-ds token system.

---

## Charts

20 chart types built on Recharts + D3. All use `var(--graph-*)` color tokens.

| Type | Description |
|---|---|
| Pie / Donut | Part-to-whole relationships |
| Line / Area | Trends over time |
| Vertical / Horizontal Bar | Comparisons |
| Combo | Bar + line on a shared axis |
| Bubble | 3-variable scatter |
| Heatmap | 2D intensity matrix |
| Treemap | Hierarchical area |
| KPI Summary | Metric cards with sparklines |
| + 12 more | Stream, Sunburst, Word Cloud, Map, Radial, and more |
