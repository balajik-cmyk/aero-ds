# Banner

A banner displays a persistent message at the top of a page or section. Unlike a Toast, it stays until dismissed or resolved.

---

## Usage

### When to use

- **System-level information** affecting the whole page: "Your trial ends in 3 days."
- **Warnings requiring attention**: "3 reviews need a response."
- **Success confirmation** that should persist until acknowledged.

### When not to use

- **Brief feedback** after a completed action — use `Toast`.
- **Form field errors** — use `InlineMessage` below the field.
- **Blocking action required** — use `Dialog`.

### Variants

| Variant | Border / icon color | Use for |
|---|---|---|
| `info` | `var(--primary)` blue | Informational — new features, tips |
| `success` | `var(--graph-green)` | Positive confirmation |
| `warning` | `var(--graph-sunflower)` | Non-blocking caution |
| `error` | `var(--destructive)` | Action required to fix an error |

---

## Content guidelines

- **Title (optional)**: noun phrase — "Action required", "Setup complete".
- **Body**: 1–2 sentences. Be specific about what happened and what to do.
- **Action button (optional)**: verb phrase — "View settings", "Upgrade plan".
- Dismissible banners should use `onDismiss`. Non-dismissible banners should resolve automatically.
