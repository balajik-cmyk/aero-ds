# Button — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Move focus to button |
| `Shift + Tab` | Move focus away |
| `Enter` or `Space` | Activate the button |

## Screen reader behaviour

- Renders as native `<button>` — no extra `role` needed.
- Text content is the accessible name — keep it descriptive.
- **Icon-only buttons** must have `aria-label`: `<Button aria-label="Delete agent">`.
- **Loading state**: add `aria-busy="true"` and update the label: `<Button aria-busy="true" aria-label="Saving…">`.
- **Disabled**: `disabled` prop — announces as "dimmed" / "unavailable". Do not use `aria-disabled` as a substitute; it keeps the button focusable.

## Colour contrast

| Variant | Foreground | Background | Ratio |
|---|---|---|---|
| `default` | `#ffffff` | `#1E44CC` | ≥ 4.5:1 ✅ |
| `destructive` | `#ffffff` | `#d4183d` | ≥ 4.5:1 ✅ |
| `outline` / `ghost` | `var(--foreground)` | `var(--background)` | ✅ |
| `secondary` | `var(--secondary-foreground)` | `var(--secondary)` | ✅ |

## Focus

`focus-visible:ring-[3px] focus-visible:ring-ring/50` — visible only on keyboard navigation, suppressed on mouse click via `:focus-visible`.
