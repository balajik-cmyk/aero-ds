# Switch

A switch toggles a single boolean setting on or off immediately — no Save button needed.

---

## Usage

### When to use

- Toggling a **system setting** that takes effect immediately (notifications, dark mode, feature flags).
- When the action is **reversible** and the result is instantly visible.

### When not to use

- **Form fields** that require submission — use `Checkbox` instead.
- **Multiple options** — use `CheckboxGroup`.
- **Binary choice that needs confirmation** — use `Dialog` + `Checkbox`.

### Label placement

The label should appear to the right of the switch (default). Always use a `<Label htmlFor="...">` — the label IS the accessible name.

---

## Content guidelines

- Labels describe the **setting being controlled**, not the state.
- ✅ "Email notifications" — ❌ "Turn on emails"
- Use noun phrases, not verbs.

---

## Behaviour

- Toggle fires immediately. If an async action is needed, disable the switch while processing and restore it on completion.
- The switch track changes: grey (off) → `var(--primary)` blue (on).
- Thumb transitions smoothly between positions.
