# Select — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Focus the trigger |
| `Space` / `Enter` / `↓` | Open the dropdown |
| `↑` / `↓` | Navigate options |
| `Enter` | Select focused option |
| `Escape` | Close without selecting |
| `Home` / `End` | Jump to first/last option |
| Type a character | Jump to matching option |

## Screen reader behaviour

Built on `@radix-ui/react-select` — uses `role="combobox"` on the trigger and `role="listbox"` on the content. Selected value is announced on change.

Pair with a `<Label htmlFor="...">` for a visible accessible name.
