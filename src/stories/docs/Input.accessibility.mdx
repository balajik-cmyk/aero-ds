# Input — Accessibility

## Screen reader behaviour

- Always pair with `<Label htmlFor="...">` — the label is the accessible name.
- Required: `aria-required="true"` on the `<input>`.
- Error: `aria-invalid="true"` + `aria-describedby="[error-id]"` pointing to an `<InlineMessage>`.
- Placeholder text is NOT a substitute for a visible label — screen readers may not announce placeholders.

## Focus

`focus-visible:ring-[3px] focus-visible:ring-ring/50` border-ring outline.
