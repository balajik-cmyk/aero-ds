# Tabs — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Move focus to the active tab |
| `←` / `→` | Move focus to the previous/next tab and activate it |
| `Home` | Move to first tab |
| `End` | Move to last tab |
| `Tab` (from tab) | Move focus into the active panel |

## Screen reader behaviour

Built on `@radix-ui/react-tabs`:
- Tab list: `role="tablist"`.
- Each tab: `role="tab"` + `aria-selected="true/false"` + `aria-controls="[panel-id]"`.
- Panel: `role="tabpanel"` + `aria-labelledby="[tab-id]"`.

## Focus

The active tab receives focus — not all tabs. Arrow keys move between tabs without `Tab` key.
