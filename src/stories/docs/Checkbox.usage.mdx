# Checkbox

A checkbox lets users select one or more options from a list, or toggle a single boolean setting.

---

## Parts

1. **Checkbox control** — the 16×16 px box showing unchecked / checked / indeterminate state.
2. **Label** — text describing what the checkbox does. Always required for accessibility.
3. **Description (optional)** — secondary text below the label for extra context.

---

## Usage

### When to use

- When users can select **multiple options** from a list (use `CheckboxGroup` for managed lists).
- When toggling a **single boolean setting** — "Remember me", "Enable notifications".
- When showing **partial selection** — use `checked="indeterminate"` for select-all patterns.

### When not to use

- **Single mutually exclusive choice** — use `RadioGroup` instead.
- **Immediate binary toggle** — use `Switch` for a more prominent on/off control.
- **Filter selection** — use `Chip` for visual filter chips in toolbars.

### Indeterminate state

Use `checked="indeterminate"` on a parent checkbox when some (but not all) children are selected. This is the standard select-all pattern — see `CheckboxGroup` with `selectAll`.

---

## Content guidelines

- Keep labels **short and descriptive** — "Send email updates", not "Email".
- **No punctuation** at the end of labels.
- For grouped checkboxes, use a consistent grammatical form across all options.

---

## Behaviour

- Individual states: unchecked → checked (toggled via `Space`).
- Grouped with `CheckboxGroup`: unchecked → indeterminate → checked on the master.
- Disabled checkboxes cannot be toggled. Use validation to explain why.
