# Avatar

An avatar represents a user or entity. It can display a photo, initials, or a fallback icon.

---

## Parts

1. **Image** — the user's profile photo (optional, renders via `<AvatarImage>`).
2. **Fallback** — initials or icon shown when no image is available.
3. **Presence indicator** — optional green dot (online status).

---

## Usage

### When to use

- To identify a **specific user** in comments, assignments, or activity feeds.
- In **navigation bars** for the current user's profile.
- In **lists and tables** to associate rows with people.

### Sizes

Use `size-6` (sm), `size-8` (md), `size-10` (lg) via Tailwind classes on the Avatar root. Default is `size-10` (40×40 px).

### Fallback text

Provide `<AvatarFallback>` with 1–2 initials: "JD" for John Doe. This renders when the image fails to load or is not provided.
