# Badge

A badge is a small label that conveys status, a count, or a category. It is non-interactive.

---

## Usage

### When to use

- Showing a **count** of items (notifications, unread messages).
- Indicating **status** (active, inactive, pending).
- Labelling a **category** or type (Beta, Deprecated, New).

### When not to use

- **Interactive labels** users can remove — use `Tag` instead.
- **Selection filters** — use `Chip`.
- **Detailed status** — use `Banner` or `Alert` for messages requiring attention.

### Variants

| Variant | Token | Use for |
|---|---|---|
| `default` | `var(--primary)` | Neutral count, primary label |
| `secondary` | `var(--secondary)` | De-emphasised label |
| `destructive` | `var(--destructive)` | Error count, critical status |
| `outline` | border only | Subtle category label |

---

## Content guidelines

- Keep badge text **1–3 words** or a number.
- For counts > 99, show "99+" (truncate).
- Status labels: sentence case — "Active", "In progress", not "ACTIVE".
