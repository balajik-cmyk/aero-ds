# Toast

Toast notifications provide brief, non-interrupting feedback about a completed action. They appear temporarily and dismiss automatically.

---

## Usage

### When to use

- **Confirming** a completed action: "Review response sent", "Agent saved".
- **Alerting** to a background event the user should know about.

### When not to use

- **Errors requiring action** — use `Banner` or `InlineMessage` which persist.
- **Confirmation before destructive action** — use `Dialog`.
- **Important info users must read** — toasts are transient; use `Alert` or `Banner`.

### Variants

| Variant | Use for |
|---|---|
| Default | Neutral info |
| Success (`toast.success`) | Completed action |
| Error (`toast.error`) | Failed action |
| Warning (`toast.warning`) | Caution, non-blocking |

---

## Content guidelines

Use the real-world templates from Figma:

- "**[Entity name]** has been **[past tense verb]**."
- "New **[entity]** **[Entity name]** has been added."
- "Changes to **[Entity name]** have been saved."

Keep messages **under 10 words**. Do not duplicate the action verb in message and icon.

---

## Behaviour

- Auto-dismiss after ~4 seconds (Sonner default).
- Supports an optional `action` with a label and callback.
- Mount `<Toaster />` once at the app root.
