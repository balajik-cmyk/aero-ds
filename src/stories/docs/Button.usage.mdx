# Button

A button triggers an event or action. They let users know what will happen next.

---

## Parts

A button consists of a **label** (required) and an optional **icon** before or after the label.

1. **Label** — text describing the action. Use verb-first phrases: "Save changes", "Delete agent".
2. **Button surface** — the interactive area with hover, active, and focus states.
3. **Icon (optional)** — only when it adds clear affordance. Do not use icons decoratively.

---

## Usage

### Use one primary action per context

Reserve `variant="default"` (blue) for the single most important action in any area. Multiple primary buttons compete for attention and confuse hierarchy.

✅ **Do** — one blue primary button alongside an outline secondary.

❌ **Don't** — two or more blue buttons in the same group.

### Match variant to importance

| Variant | Use for |
|---|---|
| `default` | Primary CTA — submit, save, create |
| `secondary` | Secondary action alongside primary |
| `outline` | Tertiary or cancel actions |
| `ghost` | Inline toolbar, table row actions |
| `destructive` | Irreversible delete — always confirm first |
| `link` | Navigation-style inline text actions |

### Size guidance

| Size | Height | Use when |
|---|---|---|
| `lg` | 44px | Hero sections, prominent standalone CTAs |
| `default` | 34px | Standard — use in most cases |
| `sm` | 32px | Compact toolbars, table row actions |
| `icon` | 34×34 | Icon-only — must have `aria-label` |

---

## Content guidelines

- **Sentence case**: "Send response" not "Send Response"
- **Verb-first labels**: "Save changes", "Delete agent", "Add contact"
- **2–4 words** max — avoid "Click here", "Submit", "OK"
- **Be specific**: "Save and continue" is better than "Next"
- Icon buttons must have `aria-label` describing the action

---

## Behavior

- The `disabled` prop disables all interaction and reduces opacity to 50%.
- For async actions, add `aria-busy="true"` and a loading Spinner inside the button.
- `asChild` allows rendering as an `<a>` tag while keeping button styles.
