# Badge — Accessibility

## Screen reader behaviour

Badges are rendered as `<span>` elements — purely visual/informational. They are announced inline as part of their parent's text context.

For **count badges** that appear next to a labelled element (e.g., a nav item), use `aria-label` on the parent to include the count: `aria-label="Inbox — 4 unread"`.

For **status badges**, ensure the status is also conveyed in text, not colour alone.

## Colour contrast

All badge variants meet WCAG 2.1 AA minimum contrast (4.5:1).
