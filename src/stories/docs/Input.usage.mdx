# Input

An input lets users enter and edit a single line of text.

---

## Usage

### When to use

- **Short text entry**: name, email, search term, URL.
- When the expected value fits on **one line**.

### When not to use

- **Multi-line text** — use `Textarea`.
- **Choosing from options** — use `Select`, `RadioGroup`, or `Chip`.
- **Date/time** — use `DatePicker` or `TimePicker`.

---

## Content guidelines

- Use a visible `<Label>` paired via `htmlFor` — never rely on placeholder alone.
- Placeholder: example value in the correct format — "e.g. john@example.com".
- Required fields: add `aria-required="true"` and mark with `*` in the label.
- Error messages: use `InlineMessage` below the field with `aria-describedby`.

---

## Behaviour

- On focus: `ring-[3px] ring-ring/50` outline.
- On error: `aria-invalid="true"` changes border to `var(--destructive)`.
