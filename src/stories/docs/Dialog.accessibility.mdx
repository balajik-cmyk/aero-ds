# Dialog — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Move focus through interactive elements within the dialog |
| `Shift + Tab` | Move focus backwards |
| `Escape` | Close the dialog |
| `Enter` / `Space` | Activate focused button |

## Screen reader behaviour

Built on `@radix-ui/react-dialog`:
- Container: `role="dialog"` + `aria-modal="true"`.
- `aria-labelledby` points to `<DialogTitle>`.
- `aria-describedby` points to `<DialogDescription>` when present.
- Focus is trapped inside the dialog while open; restored to the trigger on close.
- Opening is announced: "Delete agent, dialog".

## Focus management

On open: focus moves to the first focusable element (or the dialog itself if none).
On close: focus returns to the trigger that opened it.
