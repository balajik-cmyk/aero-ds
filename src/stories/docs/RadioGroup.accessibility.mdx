# Radio group — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Move focus to the selected radio (or first if none selected) |
| `↑` / `←` | Move to previous radio and select it |
| `↓` / `→` | Move to next radio and select it |
| `Space` | Select focused radio |

## Screen reader behaviour

- Built on `@radix-ui/react-radio-group` — uses `role="radiogroup"` on the container and `role="radio"` on each item.
- `aria-checked` is set automatically.
- Group must have a visible label via `<Label>` or `aria-label` on the root.

## Focus

24 px touch target contains a 16 px visual ring. Focus ring: `group-focus-visible:ring-[3px] ring-ring/50` on the inner visual circle.
