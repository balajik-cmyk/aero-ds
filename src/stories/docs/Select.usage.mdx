# Select

A select lets users choose one or more options from a collapsible dropdown list.

---

## Usage

### When to use

- When there are **more than 5–6 options** (fewer options → use `RadioGroup` or `Chip`).
- When a single compact trigger should reveal many choices.
- When options may be searched or loaded asynchronously.

### When not to use

- **2–4 options always visible** — use `RadioGroup` or `Chip` instead.
- **Navigation** — use `Menu` or `Tabs` for navigation actions.

### Variants

| Pattern | When |
|---|---|
| Single select | User picks one value |
| Multi-select | User picks several values; shows checkboxes |
| With search | More than ~10 options; filter by typing |
| Async | Options loaded from API; shows loading spinner |
| Grouped options | Logical groupings with `SelectGroup` + `SelectLabel` |

---

## Content guidelines

- Placeholder text: "Select [noun]" — e.g., "Select platform", "Select agent".
- Option labels: sentence case, concise.
- Group labels: sentence case, describe the category.
