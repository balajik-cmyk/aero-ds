# Avatar — Accessibility

## Screen reader behaviour

- `<AvatarImage>` must have a descriptive `alt` attribute: `alt="John Doe"`.
- If the avatar is purely decorative (e.g., next to a visible name), use `alt=""`.
- `<AvatarFallback>` (initials) is rendered as text — screen readers will announce it.
- Presence indicators (online dot) should be surfaced via `aria-label` on the parent if the presence state is meaningful: `title="Online"`.

## Colour contrast

Fallback background colours must maintain 4.5:1 contrast with the white initials text.
