# Switch — Accessibility

## Keyboard interaction

| Key | Action |
|---|---|
| `Tab` | Move focus to switch |
| `Space` | Toggle on/off |

## Screen reader behaviour

Built on `@radix-ui/react-switch` — uses `role="switch"` with `aria-checked="true/false"`. The label is announced with the state: "Email notifications, switch, on".

Always pair with a visible `<Label htmlFor="...">`.

## Focus

Focus ring: 3px `var(--ring)` around the 36×20px track. Visible only on keyboard navigation.
